# Introduction

ASCII Art clock that displays on a linux terminal.

# How to Build:

1. Ensure ncurses is installed on your system.
    - For example on Arch Linux: `sudo pacman -S ncurses`
2. Compile the program.
    - `make`

# How to Run:

`./bin/aaclock`
